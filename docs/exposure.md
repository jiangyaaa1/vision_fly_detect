# 实时曝光调节

运行 `./tools/show_camera.sh` 打开小窗口（首次升级此功能会重新部署一次板端程序）。窗口已有运行时可使用 `./tools/show_camera.sh --view-only` 只打开预览。

窗口下方取消勾选“自动曝光”，把“曝光”改成 `2.00 ms`，增益先设 `1.00 倍`，点击“实时应用并保存”。板端约每0.5秒检查曝光配置，在原有采集线程设置同一个Camera，等待数帧后读取实际曝光和增益。期间无需重新加载模型或重启识别。成功提示显示传感器读回值，并保存电脑端 `configs/maixcam.yaml` 中的三个曝光字段，其它标定、外参、模型配置保持原值。

小于3毫秒可以用2.00或2.50毫秒。若画面太暗，尝试2倍增益；增益越高噪声通常越大。自动曝光由相机自行调整，不能保证小于3毫秒。需要限定曝光时请用手动模式。

也支持终端实时调节：

```bash
cd /home/jhh/code/vision_fly_detect
/usr/bin/python3 -s tools/live_exposure.py --us 2000 --gain 1024
```

`--us 2500` 即2.5毫秒；gain1024=1倍，2048=2倍，4096=4倍。加 `--auto` 恢复自动曝光。失败时会给出连接或未收到确认的原因，不会报告为成功。板端必须先运行本次更新后的程序。

直接编辑电脑端YAML不会自动传到板子。使用窗口按钮或上述命令，才会通过SSH更新板端配置。运行中的板端会热更新曝光三个参数；模型、分辨率、标定、姿态等配置仍需按原流程重新启动。不要用第二个相机进程修改曝光，以免抢占采集硬件。

读回值可能因传感器行周期取整而与请求值略有差别。预览刷新仍显示实际收到的处理帧，没有设置10帧上限。曝光调节效果需按实际目标、距离和光照观察，不能据此保证识别距离或PnP精度。

本次实机验证：请求2500微秒读回2488微秒，请求2000微秒读回1999微秒，增益1024、手动模式1。两次操作前后板端进程PID均为684，确认没有重启推理。当前电脑主配置与板端配置已保存为手动2000微秒、增益1024。这只验证曝光热更新和传感器读回，不代表所有光照条件下都适合该曝光。
