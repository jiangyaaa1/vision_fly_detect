# 电脑端装甲板小窗口

最新：默认模型已升级为640×480 INT8主体＋BF16完整角点回归，之前在预览限10FPS时真实相机处理约19FPS；目前按用户要求取消预览限速；下文原BF16实测保留作历史对照。完整基准口径及回退步骤见[优化说明](optimization.md)。

不需要打开浏览器。模型、相机采集和四角点计算在MaixCAM Lite运行；电脑小窗口直接接收USB网络上的JPEG叠加图。底层仍使用网络传输，不能拔掉供电/网络后继续在电脑观看。

## 打开

```bash
/home/jhh/code/vision_fly_detect/tools/show_camera.sh
```

窗口立即出现，后台上传更新过的发布文件并启动板端程序。模型已包含在本机发布包里，无需另找文件下载。请先保证Lite通电并连接数据USB线。

如果板端已经运行，只想打开窗口且不重启识别：

```bash
/home/jhh/code/vision_fly_detect/tools/show_camera.sh --view-only
```

- 启动板端：重新部署并启动Lite识别。未连接时会显示错误，连接好后可重试。
- 暂停画面/空格：只暂停显示；接收线程继续丢弃旧帧，恢复时直接显示最新帧。
- 保存调试图/S：保存带检测线条的JPEG到 `captures/debug_snapshots`，不要将其当作无叠加的训练照片。
- 关闭窗口/Esc：退出电脑窗口，Lite仍继续识别。需要停止识别时执行 `python3 tools/infantry_lite.py stop`。

状态栏帧率是收到的图像帧率；“距最近接收”表示电脑收到最后一帧后经过的时间，不是相机曝光到显示的总延迟。断开网络会显示重连状态，接收恢复后自动显示。

## 卡顿优化与实测

原先关键点模式每帧合成1920×480三联图，其中两栏为空白。现在统一在 `configs/maixcam.yaml` 中设置：

```yaml
debug_layout: "overlay"
debug_jpeg_quality: 60
debug_fps: 0  # 不限速，每个处理帧都提交预览
```

只传640×480检测叠加图，不生成两个空面板，减少复制与编码开销；模型输入、角点计算及PnP精度设置不变。电脑用独立接收线程且只保留最新一帧，不排队逐帧回放。若需要轮廓三联图，可将 `debug_layout` 改回 `sheet` 后重新打包、启动。

2026-11-09实机：优化前完整流程约3.56帧/秒，优化后多组30帧统计约5.18～5.43帧/秒；采集约3～4ms，推理与解析约130～132ms，其余处理/显示约49～56ms。GUI已验证真实JPEG接收、暂停期间继续接收及恢复最新帧，并实际启动桌面窗口。

此640×480 BF16模型的推理本身仍需约130ms。更高识别帧率需要继续进行INT8量化或模型结构/尺寸适配，并用真实装甲板图片评估角点误差；不能靠刷新窗口变成30FPS。

依赖使用本机已存在的系统PyQt5；shell入口使用 `/usr/bin/python3 -s`，避免用户目录NumPy和系统OpenCV版本冲突。五组主机测试及MaixCDK RISC-V编译通过。

最新设置：`debug_fps: 0`表示不限速，窗口实际收到多少新帧就显示多少，不复制旧帧凑数。Process显示当前板端实际处理速度，预览显示实际接收速度。每帧编码增加资源开销，先前限10FPS条件下测得的约19FPS不应当作当前不限速模式的保证。

不限速实机验收：板端处理帧率中位约17.67FPS，窗口约17.52FPS，5秒接收85帧；已打开电脑原生窗口，确认不再卡在10FPS。

配置入口已统一：正常启动和小窗口按钮默认加载configs/maixcam.yaml。修改标定、外参、姿态和类别后，点击“启动板端”重新部署。历史infantry_lite/fast配置不是当前默认入口；状态命令会打印真实ACTIVE_ARGV与ACTIVE_SETTINGS并读取实际结果文件，避免把旧检测日志误认为当前定位结果。

## 实时曝光

窗口下方取消“自动曝光”，设置曝光毫秒数和增益，然后点击“实时应用并保存”。例如2.00 ms、1倍增益。窗口等板端读取传感器实际参数后显示结果，并保存电脑主配置；调节过程无需重启YOLO。首次使用本功能需更新板端程序，详见[exposure.md](exposure.md)。


## 画面旋转与镜像

窗口下方“画面方向”可选择0°、顺时针90°、180°、逆时针90°，也可勾选“左右镜像”。修改即时显示，不用重启相机或识别。方向设置保存在电脑端.local/camera_window_settings.json，下次打开窗口会恢复。已暂停显示时也可以调整方向。

旋转作用于电脑收到的完整调试画面，检测框、角点、坐标文字也随画面一起旋转或镜像。它不改变板端的识别输入、标定内参、安装外参及UART坐标轴定义；坐标文字中的数值仍按原坐标系解释。画面方向设置不能替代相机安装外参。保存调试图时按当前显示方向保存（不含窗口外的控制按钮）。

本功能需要重新打开电脑窗口加载新界面，不需要重新编译或部署板端程序：

```bash
/home/jhh/code/vision_fly_detect/tools/show_camera.sh --view-only
```

preview_camera.sh的原始网页预览、capture_camera.sh采集的训练图片/视频以及板端算法输入不受此电脑端显示设置影响。
